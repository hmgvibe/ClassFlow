# ClassFlow v2.0.0

## Downloads / 下載

- `ClassFlow-v2.0.0.apk`: Android app with Nextcloud sync / 原版，支援 Nextcloud 同步。
- `ClassFlow-Offline-v2.0.0.apk`: standalone, local-only Android app / 獨立離線版。
- `ClassFlow-Nextcloud-v2.0.0.zip`: companion app for Nextcloud 35 / 配套 Nextcloud App。
- `SHA256SUMS.txt`: SHA-256 checksums for the three packages / 三個安裝包的校驗值。

Both Android apps require Android 8.0 or newer. They can be installed together;
their databases, settings, reminders and widgets are independent.

兩份 Android App 都需要 Android 8.0 以上，可同時安裝，資料彼此獨立。

## Changes / 更新

- Simplified and Traditional Chinese across both Android editions and the Nextcloud
  web app, including forms, validation, reminders, widgets and date displays.
  Android follows the system language; the web app follows the Nextcloud user language.
  Other languages retain Traditional Chinese. User-entered content is unchanged.
- Separate offline edition: no login, network permissions or sync queue; retains
  timetable, agenda, study plans, reminders and widgets.
- Study plans: five-day date strip, morning/afternoon/evening groups, optional
  course/homework/exam links, reference times without changing manually chosen times.
- Sync conflict resolution: inspect local/server changes and choose a resolution.
- Preserve distinct timetable and agenda widget identities in optimized release builds.
- Updated launcher artwork.

新增獨立離線版、學習計劃及同步衝突處理介面；修正正式版小組件識別並更新圖標。

同步版、獨立離線版與網頁端均新增簡體中文並保留繁體。Android 跟隨系統語言，
網頁跟隨 Nextcloud 使用者語言；其他語言回退繁體，不轉換使用者輸入內容。
本次更新替換同一個 v2.0.0 Release 的安裝包；Android 內部版本號為 5。

## Upgrade / 升級注意

Install the original APK over your existing ClassFlow app; do not uninstall first.
It keeps `com.ray.classflow` and migrates the existing database without clearing it.
Back up your Nextcloud database before updating the companion app and running its
normal app upgrade/migration workflow. No server deployment is performed by this release.

The offline app uses `com.ray.classflow.offline`. It starts with its own empty database
and does not import data from the original app. There is no export feature yet;
uninstalling or clearing its data loses local content.

原版請直接覆蓋安裝，不要先卸載。學習計劃的雲端同步需要升級伺服器上的 ClassFlow App；
更新前請備份 Nextcloud 資料庫。離線版不共用或匯入原版資料，目前沒有匯出功能，
卸載或清除資料會遺失本機內容。

## Validation / 驗證範圍

Android unit tests, release lint/build, signature and package metadata checks;
Nextcloud frontend lint/type checks/build, study-plan logic tests and migration tests.
Android UI, locale switching, widget refresh and offline repository tests also passed
on an isolated Android 36 emulator. Physical-device acceptance and live Nextcloud
language switching, upgrade and cross-device sync remain unverified.
Both replacement APKs install over the previous signed v2.0.0 packages; an offline
course created before the update remains intact, and the optimized release UI was
checked in Simplified and Traditional Chinese.
